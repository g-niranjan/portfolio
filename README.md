# Niranjan Gutha — Node.js Developer Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. It is designed for free hosting on GitHub Pages and does not require a build step, server, or package installation.

## Preview locally

1. Download or clone this folder.
2. Open `index.html` in a browser.

For a local server, you can run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Before publishing

Update these items in `index.html`:

1. `YOUR_EMAIL@example.com` — replace both `mailto:` links with your professional email.
2. `YOUR_GITHUB_USERNAME` — replace it in the GitHub profile URL.
3. `YOUR_LINKEDIN_SLUG` — replace it with your LinkedIn profile slug.
4. Add your resume as `resume.pdf` in this folder, or change the resume link to match your filename.
5. Add exact employer names, role titles, and date ranges to the Experience section.
6. Add your degree, institution, graduation year, and relevant certifications.
7. Review each project description and remove or adjust anything that is confidential or not representative of your work. Add only verified impact metrics.
8. Confirm that the technology list reflects your current experience and confidence level.

The page currently uses the name and eight-year experience total provided in the conversation, plus the Node.js, Azure API Management, Node-RED, database, and Playwright/Cypress themes discussed. Since a current resume has not yet been provided, the older career timeline and education are intentionally left generic.

## Publish with GitHub Pages

1. Create a GitHub repository named `your-github-username.github.io` for a user-site URL, or create any repository for a project-site URL.
2. Upload `index.html`, `README.md`, and `resume.pdf` (after adding it) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in **Settings → Pages**.

For a user-site repository, the URL is usually `https://your-github-username.github.io/`. For a project repository, it is usually `https://your-github-username.github.io/repository-name/`.

## Notes

- The site is static; the contact links open the visitor's email client and profile links open external pages.
- Google Fonts are loaded from Google's font CDN. The page still falls back to system fonts if unavailable.
- The included project descriptions are high-level summaries and should be reviewed for accuracy and confidentiality before sharing publicly.
